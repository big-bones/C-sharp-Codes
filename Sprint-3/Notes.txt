Local temporary tables are confined to the session that created them and are automatically dropped when the session ends.
Global temporary tables are accessible to any session and remain until the session that created them ends and no other sessions are using them.
temporary tables are stored in tempdb database
you can create indexes,pk,constraints etc.. on them
local scope temp tables : create table #table_name
global scope temp tables : create table ##table_name

Views:Updatable,Simple,Schema Binding and Materialized
Simple Views can have any sort of aggregate function or joins
Updatable views can not have that
Updatable views need to have simple operations and mapping to the database columns
Whatever are the columns the view can show can also be inserted or updated
The view does not need to be schema bounded in order to be updatable
Schema Binding means that the structure of underlying table can not be changed it can not be dropped either
It is tightly coupled with the view
Materialized views are the views that have a physcial storage in the database and are also called indexed views
they are schema bounded and indexed in order to be materialized views
Advantages of views:
Abstraction : Creates an abstraction show what is important to the user
Data security : Access can be granted as and when needed
Optimization : Materialized views can have indexes so complex query logic can be saved in view and 
be made reusable
Views can have complex operations like join and can be updatable when we use instead triggers
It can update a single table and there can be only one instead view on the table
