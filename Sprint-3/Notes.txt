Temporary tables in sql are used to store the complex results of queries temporarily to optimize the query
sometimes or in the stored procedures or some session specific data is required to be temporarily stored
Local temporary tables are confined to the session that created them and are automatically dropped when the session ends.
Global temporary tables are accessible to any session and remain until the session that created them ends and no other sessions are using them.
temporary tables are stored in tempdb database
you can create indexes,pk,constraints etc.. on them
local scope temp tables : create table #table_name
global scope temp tables : create table ##table_name
Views or functions can not be created on them

Abstraction : Creates an abstraction show what is important to the user

Optimization : Materialized views can have indexes so complex query logic can be saved in view and 
be made reusable
Views can have complex operations like join and can be updatable when we use instead triggers
